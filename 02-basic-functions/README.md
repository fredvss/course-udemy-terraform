# 02 - Funcoes Basicas

Exemplos iniciais de funções do Terraform aplicadas na criação de recursos.

## Arquivos

- `main.tf`: provedor e configuração base.
- `locals.tf`: expressões e funções reutilizadas.
- `bucket.tf`: criação de bucket com valores derivados.

## Observacao

Este diretório usa estado local para facilitar o aprendizado.
