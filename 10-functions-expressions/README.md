# 10 - Funções e Expressões

Coleção de exemplos simples para estudar expressões e funções do Terraform.

## Estrutura

- `01-conditional-expressions`: expressão condicional.
- `02-for-expressions`: expressões `for`.
- `03-splat-expressions`: expressões splat.
- `04-dynamic-blocks`: blocos dinâmicos.
- `05-built-in-functions`: funções internas mais usadas.
