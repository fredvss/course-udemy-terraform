# 01 - Blocos do Terraform

Introdução aos blocos fundamentais do Terraform em um único arquivo.

## Arquivo

- `main.tf`: exemplos de `terraform`, `provider`, `locals`, `variable`, `data`, `resource`, `module`, `output`, `import`, `moved`, `removed` e `check`.

## Objetivo

Servir como referência rápida de sintaxe e responsabilidades de cada bloco.
